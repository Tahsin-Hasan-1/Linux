Linux is an open-source, Unix-like operating system kernel created by Linus Torvalds in 1991.
It serves as the core of Linux-based operating systems, called distributions (e.g., Ubuntu, Debian, and Fedora).
Linux manages hardware, processes, memory, files, networking, and system resources.
It is widely used in servers, cloud computing, supercomputers, cybersecurity, embedded systems, and personal computers.
